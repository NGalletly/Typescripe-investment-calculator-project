# Nifty Investment Calculator!

A full-stack application with a **Flask** backend and **React** frontend for investment calculations and yearly growth schedule.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, Flask, Flask-CORS

## Prerequisites

Python 3.8 or higher
Node.js 16 or higher
npm or yarn

# Installation & Setup

### Backend Setup (Flask)

Navigate to the backend folder and set up the Python environment by entering the following into terminal:

```
python3 -m venv venv
source venv/bin/activate # On Windows use: venv\Scripts\activate
```

After this you'll need to install flask dependencies using the following:

```
pip install flask flask-cors
```

#### Start the server

To start the server, run main.py:

```
python main.py
```

### Frontend

Navigate to the frontend folder and set up the React application and install dependencies with:

```
npm install
```

#### Start the development server

```
npm run dev
```
